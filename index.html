इस्तेमाल कैसे करें (Hindi Guide)

1. Statement Upload करें

अपने bank statement की photo खींचें या PDF/image file चुनें। एक साथ कई pages/files भी upload कर सकते हैं।

2. Scan & Extract दबाएँ

AI (OCR) आपकी image से text पढ़ेगा और automatically date, description, debit, credit, balance वाली rows table में डाल देगा। Note: OCR हमेशा 100% सही नहीं होता — नीचे table में gaya हुआ data manually edit ज़रूर करें।

3. Table Edit करें

किसी भी cell पर click करके उसे directly edit कर सकते हैं। Category dropdown से हर transaction को Salary, Shopping, Bills, ATM, Transfer आदि में classify करें ताकि summary सही बने।

4. Excel Download करें

"Excel Download करें" दबाने पर एक .xlsx file बनेगी जिसमें दो sheets होंगी — एक Summary (total credit/debit, category-wise breakdown) और एक Transactions (पूरी list)। यह file आप अपने accountant, client, या ITR filing के लिए इस्तेमाल कर सकते हैं।

Freelancers/Small Business के लिए Tip

हर महीने का statement यहाँ scan करके Excel में save कर लें — साल के अंत में आपके पास ready-made income/expense record होगा, जो GST filing और ITR दोनों में काम आएगा।
